# ADR 0001: Phase 0/1は単一package・素朴なf32 CPU演算

状態: 採用。数値と配列規約を追えることを優先し、各演算を明示ループにする。
既成モデル呼び出しやBLASは使わない。Matrixは不変の形状付き重み、
FfnActivationsは1回の一時値、推論状態やトークン履歴はまだ導入しない。
Phase 2以降に状態専用型を追加する。空の状態型で対応済みを装わない。

serde/serde_jsonはfixtureとローカルトレース、sha2はテスト中の参照hash検証。
版はCargo.lock、ライセンスはdependencies.md、ソースはvendorに固定。
教育用演算とQwen固有zero-centered RMSNormを明示enumで分ける。
実モデル時の高速行列バックエンド選定は別ADRで行い、参照演算を残す。

Python/PyTorchは固定公式ソースとのfixture比較にのみ利用し、通常ビルド・CLI・CIから呼ばない。
