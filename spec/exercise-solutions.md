# トレース演習の解答と理由

先に [問題](exercises.md) の予測を終えてから確認してください。
以下の数値は同梱のlesson-v1、位置0から始めた結果です。

## 問1：入力と予測

embeddingと層0のinputは同じ長さ8の配列です。
位置0のgreedy次候補は10ですが、教材は入力列[1,4,2]を固定したteacher forcingです。
そのため次の入力は4。自動生成なら10を次の入力へ渡します。
合成モデルのIDに実在の単語の意味は割り当てていません。

## 問2：正規化と残差

`after_mixer = input + mixer`、`layer = after_mixer + ffn.output`。
正規化された値はMixer/FFNへ渡す別の枝にあり、残差の値を上書きしません。
Qwenのzero-centered RMSNormの係数は `1+stored_weight` なので、保存重み0は係数1。
平方**平均**で割る処理に学習係数とepsilonが加わるため、L2ノルムが1になるとは限りません。

## 問3：FFN書込み列

unit 3の反応値は `0.058439292`、down列3の第0成分は `0.0546875`。
積は約 `0.0031958988`、観測した減少は `0.0031959005`。
全8成分の差の最大誤差は約 `5.59e-9` です。

式は `output = sum_j product[j]*down[:,j]`。
unit 3は中間成分なので列3を選びます。行3を選ぶと隠れ出力の第3成分を作る
16個の係数を読むことになり、「unit 3が全出力へ書く方向」にはなりません。

位置1の反応値は負の `-0.004596077`。同じ書込み列でも差分の符号が反転します。
「ユニットが反応したか」だけでなく、反応の符号と大きさも出力に効きます。

## 問4：Attention

head_dim=4なのでスコアの除数は2。
位置1のhead 0の確率は `[0.45035434,0.54964566]`、和は1です。
第1位置を少し強く読みますが、第0位置も参照しています。
その確率で各V成分を加重平均すると、context[0]は約 `0.7716129`。

head 1も同じKVヘッド0を使います。ただしQが別なのでスコアと確率は異なります。
位置0には参照可能な位置が自分自身の1個だけで、softmaxは必ず `[1]`。
位置2ではhead 0が `[0.3862219,0.33883798,0.27494013]` を使います。
contextの後にはsigmoidゲートとo射影があり、contextそのものを残差へ足すわけではありません。

## 問5：DeltaNet

最初のmemoryはゼロ。したがって
`S[0,0] = k[0]*beta[0]*v[0] ≈ 0.00052939774`。
初回は古いS=0なので、他の値を固定してgだけを変えてもこの結果は変わりません。
位置1以降は過去Sが非ゼロです。減衰を省くとmemory=k^T Sもdeltaも変わり、
その後のSと出力が変わります。

トレースのqはL2正規化し、さらに `sqrt(key_dim)` で割ったものです。
読み出しで再び割ると二重スケールになります。state[head,i,j]は
headごとに `i*value_dim+j` の位置へ格納されています。

## 問6：状態サイズ

KV位置数は1→2→3。各位置にはKとVが各4要素あり、両者で8要素です。
Qが2ヘッドでも、共有するKVは1ヘッドのままです。

再帰状態は `3層*2heads*4key*4value = 96要素`。
畳み込み履歴は `3層*24channels*(3-1) = 144要素`。
100位置でもこの2つは変わりません。増えるのはKVの位置列とトークン履歴です。
一時的な各stepの活性値まで保存し続けると別途メモリが増えるため、
長いprefillには `prefill_observed` を使います。

## 問7：logitsと自己回帰

最終normと埋め込み行10の内積は約 `0.8760245`。
位置0ではこれが最大なので、greedyの予測はID 10です。
logitsは確率ではありません。softmaxは順序を保つので、greedyでは省略できます。

downは中間幅16から隠れ幅8へ戻す行列、語彙射影は隠れ幅8から語彙19へ写す行列です。
このモデルでは入力埋め込みを語彙射影と共有します。
自己回帰なら、選んだIDを次の入力にし、同じrunの各層KV/再帰状態を継続します。
別の独立runでは新しい状態を使います。

位置1のgreedy候補は14、位置2は16。それでも教材の入力は[1,4,2]です。
この区別が、参照値比較で生成列の分岐と算術誤差を混同しないための基礎です。

## 問8：乖離の切り分け

| 最初の症状 | 確認すること |
|---|---|
| input_normから違う | 平方和/平均、epsilon、f32変換、1+weight係数、層の取り違え |
| 過去ありAttentionで違う | KV位置offset、層ごとの専用キャッシュ、GQA共有相手、過去Kの二重RoPE |
| down出力から違う | 行列の[out,in]規約、転置、列の選び方、バックエンド |
| 64位置前後から違う | 参照chunk境界と逐次状態の接続、conv履歴、RoPE位置、cache継続 |
| </think>後に終了 | 応答EOSと推論区切りの混同。248069は終了IDではない |

長い検証では全位置の全層出力・logits、prefill/decode後の全状態を比較します。
一致したトークン列だけで正しいと結論せず、最初に違う境界から調べてください。
