# 執筆計画｜Rustで学ぶLLM推論

## 読者と説明の順序

読者は、Rustの配列、添字、ループを読めて、LLMが出力を選ぶ仕組みに興味のある人。機械学習、Transformer、線形代数、GPUカーネルは初出箇所で説明する。上巻の合成例には実モデルの重みやGPUを要しない。下巻のGPU実測は、手元で実験する場合と保存ログを読む場合の両方を案内する。

各節は、疑問 → 小さな具体例 → 数式とRustの対応 → 実モデルまたは実装での照合、の順を基本にする。新しい用語を出すときは、何を入力にして何を出力するかを先に示す。模型で省く演算や、測定の条件を明記する。読後の確認では、読者が例の数値や入力形状を一つ変えて、結果を予想できるかを見る。

## 上巻｜Qwenの1トークンをCPUで追う

| 章 | 読後にできること | 展開 |
|---|---|---|
| 1. Qwenが「東京」を出すまで | 文字列、トークン、ID、位置、埋め込み、logitsを区別する | 同じ質問をテンプレート適用前後で符号化する。BPEの結合を小さな規則表で再現し、実IDとUTF-8の復号に戻る。 |
| 2. Transformerのブロックを手で計算する | 1ブロックを流れるベクトルと、次の位置へ残る状態を説明する | 残差・RMSNorm・FFNを短いRustと配列で読む。Attentionは同じ2位置からQ/K/Vを作り、RoPE、KV、softmax、GQAへ進む。DeltaNetは減衰・読み出し・書き込み・畳み込み履歴まで連続した例にする。 |
| 3. Rustの参照実装を、GPU実装のものさしにする | 小例から実重みまでの比較をたどり、形状・誤差・状態を確かめる | 参照ループから層の実行に戻る。手計算、fixture、上流との照合が拾える違いを示す。同じFFN射影を入力1位置と128位置で考え、下巻へ渡す。 |

上巻は、生成したIDを次の入力に渡すとき、各層が何を持ち越すかまでで一つの読書体験になる。Attentionの試作は6頁。上巻28–29頁の状態比較は、下巻の巻き戻しと対になる。

## 下巻｜QwenをMetalで速くする

| 章 | 読後にできること | 展開 |
|---|---|---|
| 4. 重みを使い回す ― Metalのprefill | CPUの行列積を、出力タイル、データロード、同期、書き戻しへ対応させる | 同じFFN射影を参照・SIMD group・Metal 4で追う。online softmaxとDeltaNetの依存を、上巻で読んだ状態と結ぶ。 |
| 5. 重みを読み切る ― Metalのdecode | 重み帯域、KVの読出し、発行の時間を分けて推定する | GEMVの実コードを読む。カーネルの粒度と融合の効果を、プロファイルと通し測定を使って比較する。 |
| 6. 1回の検証で複数トークンを進める ― MTP | 少数行をまとめて検証し、採用位置の状態へ戻す設計を説明する | 上巻の状態表で巻き戻しを追う。下書き・検証・同期・復元の費用を、同じ測定条件の記録から見積もる。 |
| 付録. ROCmの実測とCUDAでの検証設計 | 異なるGPUで同じ仮説をどう検証するか考える | ROCmの実測とCUDAでの実験設計を示す。再現手順と固定した参照を付ける。 |

下巻は上巻から章番号を引き継ぐ。Metal行列積の試作は8頁。下巻36–37頁の巻き戻しで上巻の状態表を使う。

## 上巻が下巻に渡すもの

| 上巻で計算できるようにすること | 下巻でその計算を使う場面 |
|---|---|
| FFNの同じ行を、1位置と複数位置の入力に適用する | prefillのGEMMで重みを再利用し、decodeのGEMVと比較する |
| Attentionが位置ごとのK/Vをどう読むか、DeltaNetが何を更新するかを区別する | 長文脈のKV読み出しと、投機的デコードでの巻き戻しを説明する |
| BF16行列のバイト数と、積和の回数を別々に数える | 実行時間の目安と実測を突き合わせ、演算器・帯域・発行の費用を比較する |
| 小さな配列と実モデルで、数値と状態を照合する | 実行経路を変えた後に、形・精度・生成ID・採用後の状態を確認する |

上巻には上巻だけで読める実例と演習を置く。下巻が前提にする式やデータの形は上巻で手計算し、GPUの処理と測定は下巻で導入する。紙幅はこれらを追うために必要な量から決める。

## 試作で得た紙幅と残りの作業

A5・左綴じの現時点の原稿は、上巻38頁、下巻48頁。現行の改ページを使った組版結果。テンプレートを仮適用し、章頭・見開き・主要例で区切った本文11ptの比較組版では、上巻31頁、下巻34頁だった。BPE、FFN、DeltaNet、演算量と帯域の小例を上巻へ追加した。次稿では上巻のCPU fixtureの比較と実モデルへの接続、下巻のGEMVとMTPの計算を深める。その後、重複を整理し、必要な図と演習に紙幅を配分する。

- 上巻は、現状の手計算を合成fixtureおよび実モデルのトレースに接続する。初見の読者が、入力を変えたときのID列や、1位置追加時の状態を予想できるかを確認する。
- 下巻はBF16 GEMVのlane割り当て、長文脈のKV読み出し、MTPの速度収支を具体化する。手計算と保存ログから読者が結論を再現できるかを確認する。
- 読者確認では、Rustを読めるがLLMを実装したことのない人に試作節を渡し、詰まった用語・添字と、説明を読み返した箇所を集める。
