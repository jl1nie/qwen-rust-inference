# Rustで学ぶLLM推論

Rustのコードを読めて、LLMの内部を知りたい人に向けた、技術書典用のTypst原稿です。

- 上巻「Qwenの1トークンをCPUで追う」は全巻の基礎編（第1〜6章）です。第1章で全体像を式を使わずに示し、第2章で文字列とID、第3章でprefillとdecode、第4章で数の扱い、第5章で1 layerの計算を、小さな例とRustで扱います。第6章でパラメータに介入して上巻を閉じます。
- 下巻「QwenをGPUで速くする」は第7〜13章と付録です。第7章でCPUの照合と速度の見積もりを基準として作り、Metalのprefill・decode、投機的デコード、ROCmとCUDAの実測、重みの量子化（INT8と4ビット）へ進みます。

## 組版

Typst CLIと、本文のBIZ UDPゴシック、見出しのNoto Sans CJK JP、コードのUDEV Gothicを用意します。いずれもSIL OFLで、PDFに埋め込んで頒布できます。macOSでは `brew install --cask font-biz-udpgothic font-noto-sans-cjk-jp font-udev-gothic` で入ります。リポジトリのルートから実行します。

```sh
typst compile book/upper.typ /tmp/qwen-upper.pdf
typst compile book/lower.typ /tmp/qwen-lower.pdf
```

既存の `main.typ` でも、全章を一つに束ねた通読用PDFを組めます。判型は仮のA5・左綴じです。

## 原稿へのコメント

校正の指摘と返答は、Typstの行コメントで原稿に直接書き込みます。`//` の行はPDFに出ないので、組版は変わりません。

```typst
// @@ 「区間」が唐突。前処理の説明と用語を揃えたい
// @re 1.1の前処理の説明で「区間」を定義し、ここはそのまま使う形にした。（1.1の3段落目を修正）
区間「日本の首都はどこですか」は33バイト。……
```

- `// @@` は著者の指摘。対象の行の直前に書く。複数行に分けてよい。
- `// @re` はClaudeの返答。直した内容か、直さなかった理由を書く。原稿を直したときは変えた箇所も添える。
- 決着したら著者が `@@` と `@re` を消す。続けて議論するときは `@re` の下に `@@` を足す。
- 「コメントを処理して」と頼むと、未返答の `@@` をすべて処理する。
- VS CodeのTinymist拡張を使うと、プレビューの文をクリックして該当する `.typ` の行へ移動できる。
- 入稿前に `grep -rn "// @@\|// @re" book/` でコメントが残っていないことを確かめる。

- 上巻と下巻の見開き（状態の比較と巻き戻し）は、同じ状態表でAttentionとDeltaNetの更新・巻き戻しを説明します。執筆中は流し組みで、偶数頁への位置合わせは最終組版で行います。
